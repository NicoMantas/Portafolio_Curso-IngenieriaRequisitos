# EPC28 — Criterios de Aceptación

| ID CA | Criterio de Aceptación | Feature asociada |
|---|---|---|
| CA-EPC28-01 | El sistema permite buscar alimentos por nombre y muestra definición, origen, funcionalidad metabólica, macronutrientes por 100 g, índice glucémico y alérgenos de declaración obligatoria. | F-EPC28-01 |
| CA-EPC28-02 | El sistema permite buscar enfermedades nutricionales y muestra fisiopatología, criterios diagnósticos, diagnósticos diferenciales, dianas terapéuticas, alimentos contraindicados y micronutrientes indicados. | F-EPC28-02 |
| CA-EPC28-03 | El sistema permite consultar nutrientes con tipología, subtipo, definición fisiológica, funcionalidad, enfermedades por déficit y fuentes alimentarias clave. | F-EPC28-03 |
| CA-EPC28-04 | El sistema permite consultar vitaminas y minerales con clasificación (liposoluble/hidrosoluble/mineral), funciones fisiológicas, RDA, síntomas de deficiencia y límites superiores seguros. | F-EPC28-03 |
| CA-EPC28-05 | El sistema permite crear dietas prediseñadas con objetivos terapéuticos, aporte calórico, distribución de macronutrientes, alimentos componentes y desaconsejados, vía de administración, duración, pauta posológica y suplementación sinérgica. | F-EPC28-04 |
| CA-EPC28-06 | Los catálogos son gestionables (crear, consultar, actualizar y listar) por el médico nutricionista. | Transversal |
| CA-EPC28-07 | La aplicación es instalable como PWA y permite consulta offline de catálogos previamente sincronizados. | Transversal PWA |
